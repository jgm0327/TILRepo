    * [1800. Maximum Ascending Subarray Sum](https://leetcode.com/problems/maximum-ascending-subarray-sum/description/)
    
      <details>
      <summary><strong>코드 - 구현(18분)</strong></summary>

        ```java

            class Solution {
                public int maxAscendingSum(int[] nums) {
                    int prev = -1;

                    int sum = 0, answer = 0;

                    for(int num : nums){
                        if(prev >= num){
                            if(answer < sum)
                                answer = sum;
                            sum = 0;
                        }

                        sum += num;
                        prev = num;
                    }

                    if(answer < sum)
                        answer = sum;

                    return answer;
                }
            }

        ```
